# LinkedIn versions, for her to send by hand

I have no LinkedIn tool. LinkedIn has no usable API and blocks automation, which
is the constraint this whole system was designed around. So these are written to
be pasted, not sent by the agent.

Connection notes are capped at roughly 300 characters. Each one below has a short
version for a connection request and a longer one for a message, if she is
already connected or uses InMail.
